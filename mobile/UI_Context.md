### SYSTEM THEME DESCRIPTION: INDUSTRIAL FUTURISTIC ENTERPRISE
The system utilizes a refined "Industrial Futuristic Enterprise" theme. It balances a high-tech corporate atmosphere with technical depth, avoiding oversaturated cyberpunk or gaming aesthetics. The focus is on professional data visualization, clean structural grids, and functional clarity.

- **Primary Canvas & Surfaces:** 
  * Main Background: `#0B1020` (Deep Midnight Blue) provides a stable, low-light base.
  * Panels & Cards: `#111827` and `#141B2D` (Dark Charcoal & Navy Slate) clearly isolate layout modules.
  * Elevated Borders: `#25304A` (Subtle Indigo) defines clean grid boundaries without harsh contrast.
- **Controlled Technical Accents:** 
  * Primary Titles & Icons: Light Cyan (`#00D1FF`) and Electric Blue (`#009DFF`) are used selectively for active navigation states and key operational metrics.
  * Glow Effects: Strictly minimal and professional. Glow is applied only as a subtle backdrop blur on telemetry charts and critical alert elements to draw immediate administrative attention, maintaining strict enterprise utility.
- **Infrastructure Status:** Standardized signaling system using muted variations of Green (Healthy), Amber (Warning), and Crimson (Critical) to reflect data center states instantly.
